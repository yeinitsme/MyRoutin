파일 수정 후 업데이트 반영

서비스 워커를 적용했을 때는 한 가지 규칙을 지켜주셔야 새 버전이 자동으로 반영됩니다.

이유: 서비스 워커는 속도를 위해 스마트폰에 저장된 '옛날 버전(캐시)'을 먼저 보여주므로, index.html만 수정해서 올리면 브라우저가 새 버전을 다운로드하지 않고 옛날 캐시를 계속 보여줄 수 있습니다.

해결법: index.html 코드를 수정할 때마다 sw.js 파일 안의 버전 이름도 1씩 올려서 함께 푸시해야 합니다.

JavaScript
// 변경 전
const CACHE_NAME = 'jachwi-app-cache-v1';

// index.html 수정 후 푸시할 때 함께 변경
const CACHE_NAME = 'jachwi-app-cache-v2';
이렇게 버전 숫자를 올려서 푸시하면, 기기가 sw.js의 변경을 감지하고 기존 캐시를 삭제한 뒤 새로운 index.html을 자동으로 다운로드하여 적용합니다.
